Simple Game Project in Java 

Rules: 
All Player have Name, Health + Weapon 
Health is between 0 and 100 by Default (Preset)
Special Player can have All 3 Plus Armour (Limits Damage from Gun)
Players can get Hit by Gun1 + Gun2 and Take Damage Accordingly 
Players can also Heal (Health Restored to 100)
Heal Not Possible when Health is At or Below 0 
First Player to Get Health at 0 Loses
Remaining Player Wins

Main.java
